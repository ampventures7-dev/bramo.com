# 🌴 How to Add Hotel Images and Documents Directly Here

Folder Path:
frontend/public/hotels/<your-hotel-slug>/

Example Structure:
frontend/public/hotels/
  ├── appas-beach-resort/
  │     ├── palande-beach-path.jpg
  │     ├── exterior.jpg
  │     ├── room-1.jpg
  │     └── info.txt
  │
  ├── shree-ganesh-resort/
  │     ├── exterior.jpg
  │     ├── room-ac.jpg
  │     └── info.txt

In the "info.txt" or document file, you can write:
- Property Name:
- Area (Dapoli or Harnai):
- Beach proximity:
- Description / Story:
- Amenities:
- Room Types and Prices (e.g. AC ₹2500, Non-AC ₹1800):
- Owner WhatsApp Phone:
- Owner UPI ID:
